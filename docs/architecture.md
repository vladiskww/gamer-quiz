# Архитектура Gamer Quiz

## Экраны
В `index.html` четыре экрана: стартовый, вопрос, объяснение, результат.
Виден только экран с классом `active`. Переключает их функция `showScreen()` в `app.js`.

## Схема вопроса (questions.js)
```js
{
  question: 'Текст вопроса',
  options: ['Вариант 1', 'Вариант 2', 'Вариант 3', 'Вариант 4'], // 4–6 вариантов
  answer: 0,             // индекс правильного варианта, счёт с 0
  explanation: 'Подробное объяснение, почему ответ правильный'
}
```

## Раунд
`QUESTIONS_PER_ROUND` в начале `app.js` — сколько вопросов в раунде.
Вопросы выбираются случайно из `QUESTIONS`.
`comboStreak` — сколько правильных ответов подряд; очки = 10 × комбо.
